# Orca Cube implementation plan

> Execute inline using superpowers:executing-plans; request final code review.

**Goal:** Install and run Orca on Cube with real machine resources.

**Architecture:** Preserve upstream web client and Node runtime. Add a narrow
loopback gateway and launcher for Cube's authenticated app entry point.

**Tech stack:** Node 24, pnpm, upstream orcad, React/Vite, Cube manifest.

**Spec:** `docs/superpowers/specs/2026-10-11-cube-app-design.md`

## Constraints and review focus

Keep upstream protocol and licenses; isolate test state; protect credentials;
never stop processes owned by other apps or real sessions. Validate pairing
on reload/restart, forwarded HTTPS origins, failed startup, static containment,
and duplex terminal traffic. Keep build memory bounded on shared machines.
